# Manuscript availability text to use after the public record is published

The v0.2.0 public record resolves and its downloaded archive passed checksum, statistical and privacy verification on 22 November 2026.

## Data availability

All primary data are available from public repositories. GEO accession numbers are reported in the Methods. TCGA-LIHC data were obtained through the UCSC Xena GDC hub, ICGC LIRI-JP data from Release 28 of the ICGC open object store, and the single-cell sensitivity dataset from GEO accession GSE202642. Download URLs, access dates, versions and SHA-256 values are provided in the project manifests. Analysis protocols, derived matrices, locked candidate tables, external-validation multiplicity tables, identifier-harmonization audits, single-cell sensitivity outputs and figure source data are publicly archived in Zenodo under release `v0.2.0-submission` (**https://doi.org/10.5281/zenodo.24433095**) and mirrored at **https://github.com/lory-Yu/HCC-paired-meta-analysis-reproducibility**. Third-party raw files are not redistributed and remain available from their source repositories under their respective terms.

## Code availability

The complete analysis workflow, environment lock, identifier-harmonization and denominator-verification scripts, figure-generation scripts and release-verification code are available at GitHub and archived in Zenodo under release `v0.2.0-submission` (**https://doi.org/10.5281/zenodo.24433095**). The archived release includes a root SHA-256 integrity manifest and a privacy audit. Scripts requiring third-party raw inputs must be rerun after those inputs are reacquired from the source repositories.
